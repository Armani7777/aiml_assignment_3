# Пример для демонстрации

## Вариант 1 — «Ввести тему» (основной)

На странице **Запуск** выберите **«Ввести тему»** и вставьте в поле текст ниже:

```
We study hallucination in retrieval-augmented generation for question answering with large language models. The research problem is that generated answers often contain claims that are not supported by the retrieved documents. We propose a method that retrieves passages with dense retrieval, re-ranks them, and verifies each generated claim against the evidence before producing the final answer. We evaluate faithfulness, attribution accuracy and answer quality on question answering benchmarks and compare with standard RAG baselines.
```

В поле **«Запрос в свободной форме»** вставьте:

```
5 статей 2023-2026 cs.CL
```

Остальные настройки не трогайте, «Замедлить анимацию» оставьте включённым. Нажмите **🚀 Запустить**.

> Тема на английском, потому что корпус arXiv англоязычный. Черновик система пишет по-русски.
> Если спросят: «Тема из моей диссертации — как сделать, чтобы ИИ-помощник не выдумывал факты и ссылки».

### Что получится (проверено)

- **Оркестратор** сам разберёт запрос: 5 статей, годы 2023–2026, категория cs.CL. Это видно на
  «Результатах» и в журнале (шаг `parse_query`).
- **Отобранные статьи** (все по теме):
  1. Derivation Prompting: A Logic-Based Method for Improving Retrieval-Augmented Generation (2026)
  2. Why Retrieval-Augmented Generation Fails: A Graph Perspective (2026)
  3. Chain-based Adaptive Reconfiguration Over Lattices for Hallucination Reduction (2026)
  4. EfficientRAG: Efficient Retriever for Multi-Hop Question Answering (2024)
  5. On the Capacity of Citation Generation by Large Language Models (2024)
- **Проверяющий**: нарушений 0, оценки 5 / 4 / 5, черновик принят с первого раза.
- Время — около 7 с (с замедленной анимацией).

### Что показать на «Результатах»

1. Карточка задачи: ключевые понятия (hallucination, retrieval-augmented, question answering…).
2. Вкладка **Related Work**: нажмите на ссылку [1] — откроется статья на arXiv.
3. Вкладка **Найденные статьи**: колонки «Скор», «Решение», «Обоснование». Покажите, что
   отобраны 5 статей, а остальные кандидаты отклонены с объяснением.
4. Вкладка **Проверка**: «нарушений правил нет», оценки по трём критериям.
5. Кнопка **⬇️ DOCX** — скачать готовый текст.

## Вариант 2 — без ввода текста

Если не хочется вставлять текст: **«Пример из набора»** → **«★ Демо: галлюцинации в RAG (TXT)»**.
Это тот же текст в файле. Запрос в свободной форме можно вставить тот же.

## Пример ошибки (после основного прогона)

**«Пример из набора»** → **«Неподдерживаемый формат (CSV)»** → Запустить.
Система не упадёт, а покажет: *«Формат .csv не поддерживается. Как исправить: загрузите статью в формате
TXT, DOCX или PDF»*.

Ещё вариант: **«Ввести тему»** → напишите `нейросети` → Запустить. Система ответит, что описание
слишком короткое, и подскажет, что добавить.

## Запасной пример (если спросят «а другая тема?»)

```
This research studies multi-agent systems based on large language models. The problem is how several LLM agents with different roles can cooperate to solve complex tasks reliably. We propose an orchestrator that plans the task and routes messages between specialized agents that use tools, with a critic agent that reviews intermediate results and requests revisions. We evaluate task success rate, cost in LLM calls and robustness on reasoning and coding benchmarks, and compare the multi-agent approach with a single-agent baseline.
```

Найдёт статьи про LLM-агентов (обратная связь между агентами, атаки на многоагентный консенсус,
предвзятость в многоагентных системах и т. п.).
